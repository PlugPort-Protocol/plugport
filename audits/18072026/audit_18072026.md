## 8. Potential Issues & Observations

### Minor

| # | Issue | Severity | Recommendation |
|---|---|---|---|
| 1 | **SSE heartbeat escaping:** `packages/server/src/http-server.ts:1011` writes `':\\\\n\\\\n'` (double-escaped). The SSE spec requires literal `:\n\n`. Verify this sends the correct bytes at runtime. | Low | Confirm the actual bytes written to the socket are `3a 0a 0a` (`:` + LF + LF) and not the literal string `:\\n\\n`. |
| 2 | **Timeout timer not cleared on success:** In both `packages/server/src/protocols/pg-server.ts:199-206` and `packages/server/src/protocols/mysql-server.ts:168-175`, the `setTimeout` inside `timeoutPromise` is never cleared when the query completes successfully. This means the timer handle remains in the event loop for up to 30s after each query. Under sustained load, thousands of dangling timers could accumulate. | Medium | Store the timer ID and `clearTimeout()` it in the success path. |
| 3 | **`.claude/launch.json` committed:** Commit `9bc5cab` introduced `.claude/launch.json` — this is an IDE/tool config file that likely shouldn't be in the repo. | Low | Add `.claude/` to `.gitignore` and remove from tracking. |
